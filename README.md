# 论文精读笔记

> 个人整理的论文精读笔记库，按学科分模块存放。目标读者是**基础较弱的学习者**（大一新生，具备基础微积分与线性代数），采用**刨根问底**的方式讲解：不满足于"是什么"，一路追问到"为什么"。

- **对象与深度**：为大一新生写。每个公式只说明"表达什么关系"，**不推导**；所有符号、单位、数量级都解释到位。
- **结构**：一句话看懂 → 背景动机 → 核心概念 → 逐节精读 → 数学建模 → 风险 / 局限 / 未来方向 → 对比 → Q&A → 自测清单 → 词汇表。
