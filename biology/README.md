> 返回：[论文精读笔记总索引](../README.md)

关注生命现象背后的**机制**：不发明新器件、不提出新设计，而是回答"某个生物学过程为什么会这样"——从分子通路、表观遗传，到组织与器官层面的因果链。

> 与 BME 的分界：**BME 收"做出了什么新东西"（传感器、机器人、材料、系统）；生物收"搞清了什么道理"（机制、因果、规律）。**
