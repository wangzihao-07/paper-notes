## 新增一篇生物笔记

1. 建目录 `biology/papers/<论文slug>/`，笔记文件与目录同名：`<论文slug>.md`
2. 自绘图放 `images/`；**论文原图**放 `images/paper-figures/`，并在那里写一份 `NOTICE.md`（出处、DOI、版权归属）
3. 论文原图的别名统一用 `fig<N>-<内容-短横线>.png`
4. 在上面「已收录」表里加一行，并把标题里的篇数改掉；同时更新根目录 `README.md` 的模块表

> 说明：这个模块与 [BME](../bme/) 也有重叠（比如生物材料、递药载体）。判断标准同上：**问"机制是什么"放这里，问"怎么做成器件"放 BME。**
