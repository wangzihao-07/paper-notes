## 新增一篇 AI 笔记

1. 建目录 `ai/papers/<论文slug>/`，笔记文件与目录同名：`<论文slug>.md`
2. 自绘图放 `images/`；**论文原图**放 `images/paper-figures/`，并在那里写一份 `NOTICE.md`（出处、arXiv 编号或 DOI、版权归属）
3. 论文原图的别名统一用 `fig<N>-<内容-短横线>.png`
4. 在上面「已收录」表里加一行，并把标题里的篇数改掉；同时更新根目录 `README.md` 的模块表

> 说明：AI 论文大多有 arXiv 版本，图片版权通常归作者所有（CC BY 与否需逐篇核对，不能默认）。**不要因为"是预印本就当作公有领域"。**
